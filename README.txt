CBG's Lair — Chaos Gremlins front-end prototype

HOW TO PREVIEW
1. Extract this ZIP.
2. Open index.html in a modern browser.
3. Click a category card to open its channel list.
4. Use “All categories” to return to the homepage.
5. Hover or keyboard-focus the cards to see the purple pulse/glow effects.

WHAT IS INCLUDED
- Responsive two-column mobile category layout and three-column desktop layout
- Gothic headings, purple panels, subtle gradient header, clean no-picture design
- Pulsing hover effect on category cards and glowing hover states on buttons
- Category pages with text and VC channel labels
- Account menu placeholder

IMPORTANT
This is a front-end prototype. Real account registration/login, saved messages, moderation permissions, and live voice calls require backend services and are not implemented yet. Google Fonts are loaded from the internet; fallback fonts are provided if offline.
